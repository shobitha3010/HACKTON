# Fake Job Detector
A simple web-based Fake Job Detector that helps users identify suspicious job postings 
based on common scam indicators. Built using HTML, CSS, and JavaScript.

---

## Problem Statement
Many job seekers fall victim to fake job postings that ask for money, personal details, 
or offer unrealistic salaries. This project helps users detect such fake jobs quickly.

---

## Solution
The Fake Job Detector analyzes job descriptions using common red flags such as:
- Requests for registration fees
- Unrealistic salary offers
- No company details
- Urgent hiring messages
- Poor grammar

Based on these indicators, it shows whether the job is likely fake or safe.

---

## Features
- Simple and user-friendly interface
- Paste and analyze job descriptions
- Instant result display
- Fully offline and browser-based

---

## Technologies Used
- HTML
- CSS
- JavaScript

---

## How to Run the Project
1. Download or clone the repository
2. Open fake_job_detector.html in any browser
3. Paste the job description
4. Click *Check Job*
